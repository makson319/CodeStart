# Задание для агента

Это подготовленное агентом техническое задание по запросу студента,
а не отдельный исторический промпт пользователя и не скриншот диалога.

Доработать приложенный index.html сайта CodeStart из ЛР4. Сохранить дизайн,
тексты и адаптивную сетку. В отдельной ветке feature/photos заменить три CSS-заглушки
карточек проектов фотографиями из assets/images. Добавить осмысленные alt,
размеры изображений, lazy loading и object-fit. Сохранить источники фото.
В main исправить обработку имени из пробелов и закрытие меню по Escape.
Создать docs/project-guide, README и инструкцию публикации. Зафиксировать
изменения и выполнить merge --no-ff с main. Проверить страницу на компьютере
и смартфоне. Не утверждать, что GitHub Pages или fork созданы без проверки.
