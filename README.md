# CodeStart

[![CI/CD](https://github.com/makson319/CodeStart/actions/workflows/deploy.yml/badge.svg?branch=main)](https://github.com/makson319/CodeStart/actions/workflows/deploy.yml)

Учебный лендинг для начинающих изучать программирование. Продолжение проекта из ЛР4; в ЛР5 использованы Git, ветви, слияние и GitHub Pages.

**[Открыть сайт](https://makson319.github.io/CodeStart/)**

## Запуск

Откройте `index.html` в браузере. Сборка и установка пакетов не требуются. Для локального HTTP-сервера можно использовать `python -m http.server 8000`.

## Файлы проекта

- `index.html` — разметка и логика сайта.
- `style.css` — стили и адаптивная вёрстка.
- `assets/images/` — три фотографии, используемые в карточках проектов.
- `assets/images/SOURCES.md` — ссылки на оригиналы фотографий и условия использования.
- `.github/workflows/deploy.yml` — проверки и публикация через GitHub Actions.
- `scripts/` — проверка локальных ресурсов и сборка в `_site`.

## Проверка

Семь проверок обработчиков JavaScript с моделью DOM пройдены. Проверены цели внутренних ссылок, уникальность id и читаемость фотографий. Опубликованный сайт открыт в браузере: три фотографии загружаются, форма показывает демонстрационное подтверждение. Отдельная проверка мобильного представления ещё требуется.

Форма демонстрационная: данные не сохраняются и не отправляются на сервер. Фотографии иллюстрируют работу с кодом и не являются изображениями готовых учебных проектов.


## ЛР6: автоматические проверки и публикация

Индивидуальный проект: проверка HTML/CSS и локальных ресурсов перед публикацией CodeStart, статус-бейдж в README.

1. `npm ci` — установить зафиксированные зависимости.
2. `npm run check` — HTMLHint, Stylelint, проверка файлов, внутренних ссылок и alt-текстов.
3. `npm run build` — собрать HTML, CSS и изображения в `_site/`.

Workflow выполняет проверки для push в main и lr6/cicd, а также pull request в main. Задание deploy запускается только в main и только после успешного validate (`needs: validate`). Ошибка проверки блокирует публикацию. Для GitHub Pages требуется источник **GitHub Actions** в Settings → Pages.

В артефакт публикации включаются только файлы сайта; инструменты разработки и отчёты в него не попадают. Статический сайт не требует компиляции: сборка подготавливает каталог публикации.
