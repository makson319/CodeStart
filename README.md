# CodeStart

Учебный лендинг для начинающих изучать программирование. Продолжение проекта из ЛР4; в ЛР5 использованы Git, ветви, слияние и GitHub Pages.

**[Открыть сайт](https://makson319.github.io/CodeStart/)**

## Запуск

Откройте `index.html` в браузере. Сборка и установка пакетов не требуются. Для локального HTTP-сервера можно использовать `python -m http.server 8000`.

## Файлы проекта

- `index.html` — разметка, стили и логика сайта.
- `assets/images/` — три фотографии, используемые в карточках проектов.
- `assets/images/SOURCES.md` — ссылки на оригиналы фотографий и условия использования.
- `AGENT_TASK.md` — техническое задание для агента, подготовленное при выполнении работы; не заменяет скриншот диалога.
- `.nojekyll` — файл для публикации статического сайта через GitHub Pages.

## Ветки

| Ветка | Назначение |
| --- | --- |
| `main` | Опубликованная версия сайта |
| `design` | Сохранённая исходная версия сайта |
| `photos` | Первый вариант подбора фотографий; PR № 1 закрыт, файлы не включены в main |
| `lr5/photos-and-fixes` | Фотографии и исправления, объединённые с main через PR № 2 |

Ветки сохранены для демонстрации работы с Git в ЛР5.

## Результаты ЛР5

- Три локальные фотографии в карточках проектов, альтернативные тексты и отложенная загрузка.
- Проверка имени из пробелов и очистка устаревшего сообщения формы.
- Закрытие меню по Escape с возвратом фокуса на кнопку.
- [Слияние изменений с main — PR № 2](https://github.com/makson319/CodeStart/pull/2).
- [Форк учебного внешнего репозитория Spoon-Knife](https://github.com/makson319/Spoon-Knife).
- Публикация через GitHub Pages из ветви main, корневой каталог.

## Проверка

Семь проверок обработчиков JavaScript с моделью DOM пройдены. Проверены цели внутренних ссылок, уникальность id и читаемость фотографий. Опубликованный сайт открыт в браузере: три фотографии загружаются, форма показывает демонстрационное подтверждение. Отдельная проверка мобильного представления ещё требуется.

Форма демонстрационная: данные не сохраняются и не отправляются на сервер. Фотографии иллюстрируют работу с кодом и не являются изображениями готовых учебных проектов.
