# CodeStart

[![Deploy](https://github.com/makson319/CodeStart/actions/workflows/deploy.yml/badge.svg?branch=main)](https://github.com/makson319/CodeStart/actions/workflows/deploy.yml)

Учебный сайт о начале изучения программирования.

[Открыть сайт](https://makson319.github.io/CodeStart/)

Сайт состоит из `index.html`, `style.css` и изображений в `assets/images`.
Для просмотра достаточно открыть `index.html` в браузере.

При изменениях в `main` GitHub Actions проверяет HTML и публикует сайт в GitHub Pages.
Индивидуальная часть ЛР6 — проверка HTML перед публикацией и статус-бейдж выше.
